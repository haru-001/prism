# 画图工作台 + 提示词库：改动说明

左栏新增两个入口：**画图**（`/draw`）和 **提示词**（`/prompts`）。聊天里的生图（生图开关、`/图 描述`）照常可用，没有改动。提示词库的逻辑参考了 haru（你之前的提示词项目），按 Prism 的结构重新实现。

## 页面怎么用

### 画图 `/draw`
- 左边是参数，右边是生成队列和作品。手机上参数在上、作品在下，「生成」按钮吸在底部。
- **模型**：列出所有打了「生图」标签的模型，按渠道分组。比例、张数、质量会按模型自动切换（参考 haru 的 imageProfile，只保留 Prism 后端真能传到上游的参数）：
  - gpt-image：自动 / 1:1 / 2:3 / 3:2，质量低、中、高
  - dall-e-3：1:1 / 9:16 / 16:9，标准、HD（多张时并发请求）
  - Gemini 渠道：只有 1:1、2:3、3:2
  - 豆包 Seedream、Qwen-Image、Kolors、FLUX 等：各自常用的尺寸
- **参考图**：最多 4 张，可以点「添加」、拖进来或直接粘贴。
- **生成**：Ctrl/⌘+Enter。可以连续提交，每个任务单独排队、计时、可以停止，失败的有重试。切到别的页面再回来，任务照常进行，结果也还在。
- **断线找回**：如果请求已经发出、连接却断了（换网络、网关超时），会自动去图库里找这次的结果（同一段提示词、同一个模型、提交之后才存的图），找到就照常显示。页面刷新前还在生成的任务也会找一次。
- **作品**：「本次生成」+「历史作品」（就是图库里的图片，每次加载 48 张，可以继续加载）。点开一张可以保存、复用提示词（连模型和参数一起填回去）、再来一次、作参考图、发到对话、复制提示词、删除。
- 上次选的模型和参数、没写完的描述都会记住。

### 提示词 `/prompts`
- **灵感库**：内置「水仙的AI提示词」6,601 条（15 大类、79 小类，带示例图）。
  - 大类标签（带数量和颜色）→ 点开后显示小类；热门标签；「今日推荐」每天一组，「换一批」可换。
  - 搜索标题、分类、风格标签；纯字母时同时按**拼音首字母**搜（如 `sbpk` 找到「赛博朋克」）；勾选「搜索正文」会下载全部正文再搜。按 `/` 聚焦搜索框。
  - 排序：推荐（各大类轮流排，首页不会被一个分类占满）/ 最热 / 最新 / 随机。
  - 每次显示 48 张卡片，滚动到底部附近自动加载下一批；封面是固定比例的懒加载图片，加载时不会跳动。
  - **详情抽屉**：大图和多图切换、点图看大图；`{argument name="…" default="…"}` 变量自动变成填空，复制和画图时自动填入（另有「复制原文」）；← → 翻上一条 / 下一条，Esc 关闭。
  - 按钮：**用这个画**（把填好的提示词和**建议比例**带到画图页，画图页会自动选最接近的尺寸）、发到对话（新对话的生图模式）、复制、收藏、存为我的提示词。
- **我的**：自己写的提示词，可以新建、编辑、删除、分类，支持同样的变量写法；保存在服务器上，手机和电脑都能用。用某条画出的第一张图会自动成为它的封面。
- **收藏**：也保存在服务器上。**最近**：复制、去画图、发到对话时记一笔，只存在这台设备上。两处都可以搜索、复制、去画图、回到原条目，以及**导出 / 导入**（导出的文件包含我的提示词、收藏和最近使用；也能导入 haru 的备份文件）。
- **R18**：默认隐藏，第一次进入时要确认已满 18 岁（只在这台设备上记住，可以在「显示设置」里撤销）。确认后才会显示「大凶」分类，以及 R18 库：亚洲写真（上游精选 43 条 + 本地组合 2,400 条）和英文精选（3,000 条，分块按需加载）。详情可以切换中文 / English，英文里的人物占位名可以换成角色名或 LoRA 触发词。数据和 haru 的 R18 包相同。
- **显示设置**（右上角齿轮）：封面加载方式（默认经本站转发缩略图，也可以选直连图床）、隐藏不想看的大类、成人内容开关、R18 详情默认语言。
- **数据更新**（右上角）：显示本地版本、上游最新版本和最后一次提交说明；点「同步」，服务器会从 GitHub 拉最新数据重新生成。新数据全部生成并存好之后才切换，失败不影响现有数据；上游内容没变时只更新版本号。同步过的数据可以「恢复内置数据」。
- 页面底部有「水仙的AI提示词」的署名和仓库链接（许可证要求）；R18 分页底部有对应数据来源。README 末尾也加了「致谢与数据来源」。

## 速度和体验
- **提示词数据**：沿用 haru 的格式。首屏只下载约 160KB 的索引（`.json.gz`，浏览器自己解压），页面渲染时就开始预加载。正文 250 条一块，打开详情时才下载；鼠标移到卡片上时提前下载。拼音表（18KB）只在用到时才下载。所有数据文件的地址都带版本号，浏览器缓存一年，第二次打开不再请求；同一个文件同时只请求一次，结果留在内存里，换页面再回来不用重新下载。
- **封面**：经 `/api/prompt-lib/img/…?w=360` 转发，服务端压成 360px 的 WebP，CDN 和浏览器缓存一年。浏览器不直连外部图床，和项目「只访问本站」的做法一致。
- **按需加载**：R18 库（组合库词表、中文要点词表）、数据更新面板都是单独的代码块，用到才下载。提示词页比聊天页只多约 20KB（gzip）的 JS，画图页多约 12KB。
- **我的提示词 / 收藏**：先显示这台设备上次的缓存，同时在后台向服务端确认最新的。
- **图库页**：原来一次渲染全部（最多 2000 张），改成先渲染 60 张，滚动到底部附近再继续加载。批量选择时仍然显示全部。
- `/api/gallery` 新增可选参数 `kind=image|video`、`offset`、`limit`（画图页只拿一页图片）；不带参数时行为和原来一样。
- 加载时显示骨架屏，不会出现空白；浅色和深色模式都检查过。

## 同步数据存在哪里
- 用 MySQL 时：每个分块按 base64 存成 `prism_kv` 里的一行（`prism:plib:f:<版本>:<文件>`），共约 6MB；清单在 `prism:plib:manifest`。切换到新版本后，旧版本会删掉。
- 本地开发（没有 DATABASE_URL）时：存在 `.data/prompt-lib/<版本>/`。
- 服务器连 GitHub 慢时可以设置 `PROMPT_LIB_GITHUB_PROXY`（例如 `https://ghproxy.net/`）。示例图的尺寸（用来给出建议比例）来自上游站点的 `list.part*.json`，拿不到时只是没有建议比例，不影响同步。

## 没做的部分和原因
- **原来任务里的「自写 80 条入门提示词」和「外部提示词源 URL」**：按新的要求，改成内置完整的水仙库，再加「数据更新」，所以这两项都不需要了。「隐藏分类」保留在显示设置里，带「大凶」「诱惑」「NSFW」「R18」字样的分类默认隐藏，确认 18+ 后才显示。
- **R18 库不做在线同步**：haru 的 R18 同步要下载约 80MB 的 CSV 再筛选，不适合放在 Vercel 函数里。现在用随代码发布的那份数据（和 haru 的数据包相同）。
- **反向提示词**：Prism 的生图接口没有反向词参数，所以画图页不提供（haru 的部分格式有）。
- **备份**：「设置 → 备份与恢复」还没有包含我的提示词和收藏（`backup.ts` 这次没有改）。可以先用提示词页的「导出」。
- **断线找回的范围**：服务端生图时会跟着浏览器的请求一起取消，所以刷新或关掉页面通常会中断生成。找回只覆盖「服务端已经存好图、但响应没送到」的情况。
- **只做了这些检查**：`tsc` 和 `next build` 都通过；用本地存储模式、模拟上游和无头浏览器（桌面浅色、手机深色）测过：灵感库加载、拼音搜索、详情翻页、带比例去画图、生成成功、断线找回、发到对话、18+ 确认、R18 库、我的提示词的变量填写、收藏，以及真实从 GitHub 同步、读取和恢复。**没有在 MySQL 和 Vercel 上测过**（同步数据写进 MySQL、函数包里能不能读到 `data/prompt-lib`），也没有在真机安卓 Chrome 上测过。仓库里没有 ESLint 依赖，所以没有跑 lint。
